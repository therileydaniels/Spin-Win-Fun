This is Phase 6 of 9. We're adding the ability to save and load wheel configurations.

CONTEXT:
Phases 1-5 are complete — we have a working wheel with rigging, customization, presentation mode, and user accounts. The Wheels table already exists in the database. Now users need to save their wheels.

---

PHASE 6 SCOPE — Build only this:

1. **Save Current Wheel**
   - "Save Wheel" button in the Wheel Settings panel
   - If user is NOT logged in: prompt them to sign in first
   - If user IS logged in: show a modal to name the wheel
   - Default name: "My Wheel" or "Untitled Wheel"
   - Save to database: name, segments (names, colors, probabilities)
   - Show success message: "Wheel saved!"

2. **My Wheels Dashboard**
   - New page or panel: "My Wheels"
   - Link in header (only visible when logged in)
   - Shows list of user's saved wheels:
     - Wheel name
     - Number of segments
     - Date saved/updated
     - Load button
     - Delete button
   - Empty state if no wheels: "No saved wheels yet. Create one and save it!"

3. **Load a Saved Wheel**
   - Click "Load" on any saved wheel
   - If current wheel has unsaved changes, show confirmation: "Load this wheel? Any unsaved changes will be lost."
   - Replace current wheel with saved configuration
   - Redirect to main wheel page with that wheel loaded

4. **Update Existing Wheel**
   - If current wheel was loaded from a save, show "Save" (update) vs "Save As" (new copy)
   - "Save" updates the existing saved wheel
   - "Save As" creates a new saved wheel with a new name

5. **Delete Saved Wheel**
   - Click delete button on a saved wheel
   - Confirmation: "Delete [wheel name]? This cannot be undone."
   - Remove from database

6. **Free Tier Limit**
   - Free users: max 2 saved wheels
   - Show message when at limit: "You've reached the free limit (2 wheels). Upgrade to save unlimited wheels."
   - Don't enforce for admin role (I should have unlimited)

---

UI DESIGN:
- My Wheels page should match our gradient/modern aesthetic
- Saved wheels displayed as cards with subtle shadows
- Clean, scannable list
- Mobile responsive

- No ads — Phase 9
