  "orientation": "portrait",

    {

    {
      "src": "/icons/icon-512.png",
      "sizes": "512x512",
      "type": "image/png",
      "purpose": "any maskable"
    }
  ]
}

Use our brand colors:
- theme_color: #A855F7 (purple)
- background_color: #0f172a (dark mode background)

PART 3: CREATE APP ICONS

Create simple app icons for the PWA:
- 192x192 PNG
- 512x512 PNG

The icon should be:
- Simple wheel or spinner design
- Use our purple gradient colors (#A855F7, #EC4899, #0EA5E9)
- Look good on both light and dark home screens
- Work as a maskable icon (important content in center safe zone)

Place icons in client/public/icons/ folder.

PART 4: ADD META TAGS TO INDEX.HTML

Add these to the <head> of client/index.html:

<!-- PWA Meta Tags -->
<link rel="manifest" href="/manifest.json">
<meta name="theme-color" content="#A855F7">
<meta name="apple-mobile-web-app-capable" content="yes">
<meta name="apple-mobile-web-app-status-bar-style" content="black-translucent">
<meta name="apple-mobile-web-app-title" content="[App Name]">
<link rel="apple-touch-icon" href="/icons/icon-192.png">

<!-- SEO Meta Tags -->
<meta name="description" content="A customizable wheel spinner for decisions and games. Set custom probabilities and spin to win!">
<meta name="keywords" content="wheel spinner, prize wheel, decision maker, random picker">
