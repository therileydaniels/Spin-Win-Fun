Add a cute "Add to Home Screen" button in the header that prompts users to install the PWA.

**Goal:**
Create an install button in the header that:
- Shows the QuickWheel logo icon
- Says "Install App" or "Add to Home"
- Only appears when app is installable (not already installed or in browser that doesn't support PWA)
- Triggers the browser's PWA install prompt when clicked

---

**Implementation:**

**1. Create Install Button Component (client/src/components/InstallButton.tsx):**

The component should:
- Use the browser's `beforeinstallprompt` event
- Hide itself if app is already installed or not installable
- Show the QuickWheel logo icon (use the logo from public/favicon-32x32.png or logo.png)
- Have cute styling that matches the app's gradient theme
- Handle the install flow when clicked

Key functionality:
```typescript
// Listen for beforeinstallprompt event
// Store the event for later use
// Show button only when prompt is available
// On click: call prompt.prompt() and handle result
// Hide button after successful install
```

**2. Add to Header (client/src/pages/Home.tsx or wherever header is):**

Position the button in the header area, likely:
- Between the logo and the Customize button, OR
- On the left side near the logo, OR
- In the top-right icon cluster

Choose whichever looks best visually.

**3. Button Styling:**

Make it cute and match QuickWheel's aesthetic:
- Small and unobtrusive but clear
- Include the QuickWheel icon (16x16 or 24x24 size)
- Text: "Install" or "Add to Home" or "📱 Install App"
- Gradient purple/pink background OR outlined style
- Rounded corners
- Subtle hover effect
- Match the Customize button style

Example styling ideas:
- Pill-shaped button with icon + text
- Just an icon with tooltip on hover
- Small gradient button with download icon

**4. Progressive Enhancement:**

The button should:
- Only show on supported browsers (Chrome, Edge, Safari 16.4+, Firefox on Android)
- Not show if user has already installed
- Gracefully hide if PWA isn't properly configured
- Show a success message or toast after install (optional but nice)

**5. Icon Source:**

Use one of these for the icon:
- `/favicon-32x32.png` (resize to 20x20 or 24x24)
- `/logo.png` (crop to just the icon, resize small)
- Or use a download/install icon from an icon library

---

**Expected Result:**

✅ Cute button appears in header
✅ Shows QuickWheel icon
✅ Only visible when app is installable
✅ Clicking triggers browser's install prompt
✅ Hides after successful installation
✅ Matches app's design aesthetic
✅ Works on Chrome Android, Edge, Safari iOS 16.4+

---

**Test After:**
1. Open app in Chrome on Android (or Chrome desktop)
2. Button should appear in header
3. Click button → see browser's install prompt
4. Install app → button disappears
5. Open installed app → button should not show (already installed)
